# Контракт REST API

Версия 1.0. Базовый путь — `/api/v1`. Тела операций записи передаются в JSON. Описания типов и операций доступны в [OpenAPI](openapi.json). Запущенный сервер выдаёт ту же схему по `/openapi.json` и страницу Swagger UI по `/docs`. Загрузка интерфейса Swagger с CDN требует доступа в интернет, JSON доступен локально.

| Метод и путь | Назначение | Доступ |
|---|---|---|
| GET `/health` | готовность HTTP-сервера | открытый |
| POST `/auth/login` | вход с полями `username`, `password` | открытый |
| DELETE `/auth/session` | завершение текущей сессии | все роли |
| GET `/departments`, `/disciplines`, `/years` | справочники для заполнения форм и фильтров | все роли |
| GET `/teachers` | поиск, фильтр года и ставки, сортировка | все роли |
| GET `/teachers/{teacher_id}` | карточка и суммарные часы | все роли |
| POST `/teachers`, PUT/DELETE `/teachers/{teacher_id}` | изменение карточек | администратор, заведующий кафедрой |
| GET `/pools` | строки плана и остатки, фильтры периода и кафедры | все роли |
| POST `/pools`, PUT/DELETE `/pools/{pool_id}` | изменение общего плана | администратор, заведующий кафедрой |
| GET `/assignments` | назначения по периоду, кафедре и преподавателю | все роли |
| POST `/assignments`, PUT/DELETE `/assignments/{assignment_id}` | назначение, изменение и возврат часов | администратор, заведующий кафедрой |
| GET `/reports/workload/{format}` | ведомость XLSX или PDF по тем же фильтрам | все роли |

Вход возвращает `access_token`, `token_type`, `expires_in` и сведения о пользователе. В запросах к закрытым маршрутам отправляется заголовок `Authorization: Bearer <access_token>`. Сессия действует один час в памяти процесса. Сервер определяет роль по текущей записи пользователя. Смена пароля или логина, удаление пользователя и перезапуск сервера завершают его сессию. Запрос выхода возвращает HTTP 204 с пустым телом. Для учебного развёртывания используется один рабочий процесс.

Для назначения отправляется `POST /api/v1/assignments` с телом:

```json
{"teacher_id": 7, "pool_id": 12, "hours_lecture": 12, "hours_practice": 24}
```

Идентификаторы берутся из списков API. Год, семестр и дисциплина определяются сервером по плану. Успешное создание возвращает HTTP 201 и поля `id`, `message`. Полное редактирование отправляется тем же телом методом PUT по адресу назначения. Пустой фильтр опускается. Семестр `0` используется для просмотра ранее перенесённых записей с неизвестным периодом.

Ошибки маршрутов описаны моделью `ApiProblem` со строковым полем `detail`. HTTP 401 означает, что нужно войти, 403 — что роль не допускает изменения, 404 — что запрошенная карточка отсутствует, 409 — что операция отклонена по правилам учёта или запись уже недоступна, 422 — что входные поля не соответствуют схеме. Идентификаторы записей должны быть положительными. Ошибка формирования ведомости возвращает 500. Успешная выгрузка возвращает файл с заголовком `Content-Disposition`.

При изменении формата запросов и ответов обновляются модели в `server/api.py`, вызовы клиента, тесты и экспортированная JSON-схема. Номер версии пути сохраняется для совместимых изменений. Несовместимые изменения требуют отдельной версии маршрутов и проверок.
