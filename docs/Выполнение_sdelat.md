| Годовая нагрузка из общего списка | общий план по году, семестру, группе и дисциплине, с теорией, практикой и числом недель |

## Проверки

Команда `python scripts/check_project.py` проходит. Подробности: [протокол](TEST_REPORT.md).

Рабочая база не менялась при разработке: проверки выполнялись на временных данных и копии исходного SQLite-файла. При первом запуске новой версии старая SQLite обновится автоматически после создания `.before-v2.bak`.

У старых записей семестр и группа неизвестны. Они сохраняются в архивных строках; число недель изначально равно 18. Эти сведения нужно уточнить по фактическому плану. PostgreSQL и установка на Windows/macOS в данном прогоне не проверялись.
